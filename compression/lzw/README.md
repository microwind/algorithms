# LZW压缩算法

## 问题描述

LZW (Lempel-Ziv-Welch) 是一种无损数据压缩算法，广泛应用于GIF图像压缩和Unix的compress命令中。

## 算法思想

### 核心原理

1. **字典构建**：动态构建编码字典
2. **字符串匹配**：查找最长匹配字符串
3. **编码输出**：输出字典索引
4. **字典更新**：将新字符串加入字典

### 压缩过程

1. 初始化字典，包含所有单字符
2. 读取输入字符串，查找最长匹配
3. 输出匹配的字典索引
4. 将匹配字符串+下一个字符加入字典
5. 重复直到输入结束

### 解压过程

1. 初始化字典，包含所有单字符
2. 读取编码索引，输出对应字符串
3. 将前一个输出字符串+当前输出字符串的首字符加入字典
4. 重复直到编码结束

## 复杂度分析

- **时间复杂度**: O(n)，其中n是输入长度
- **空间复杂度**: O(n)，用于存储字典
