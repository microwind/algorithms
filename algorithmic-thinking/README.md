# 算法思想 Algorithmic Thinking

本文件夹包含5大核心设计范式的深入学习指南，这些是解决复杂算法问题的基础思想框架。

```

└── branch-and-bound/          # 5. 分支限界（Branch and Bound）
```

## 5大核心设计范式简介

### 1. 贪心（Greedy）
- **核心**：在每一步选择当前最优解，期望累积得到全局最优结果
- **适用**：问题具有贪心选择性质和最优子结构
- **应用**：背包、MST、Dijkstra、Huffman编码
- **文件夹**：`greedy-algorithm/` - 包含详细实现和多语言代码示例

### 2. 分治（Divide and Conquer）
- **核心**：分解 → 递归求解 → 合并
- **适用**：子问题相互独立，存在自然分割点
- **应用**：排序、二分查找、矩阵乘法、FFT
- **文件夹**：`divide-and-conquer/` - 包含详细实现和多语言代码示例

### 3. 动态规划（Dynamic Programming）
- **核心**：重叠子问题 + 最优子结构 + 状态转移
- **适用**：具有重叠子问题和最优子结构的问题
- **应用**：背包、LCS、编辑距离、路径问题
- **文件夹**：`dynamic-programming/` - 包含详细实现和多语言代码示例

### 4. 回溯（Backtracking）
- **核心**：DFS探索 + 约束检验 + 状态回溯
- **适用**：需要枚举所有合法方案的问题
- **应用**：排列、组合、N皇后、数独
- **文件夹**：`backtracking/` - 包含详细实现和多语言代码示例

### 5. 分支限界（Branch and Bound）
- **核心**：回溯 + 界限估计 + 提前剪枝
- **适用**：需要求最优解的问题
- **应用**：TSP、整数规划、任务分配
- **文件夹**：`branch-and-bound/` - 理论框架和应用指南

## 学习路径

### 第一阶段：基础（必学）
1. **贪心** - 理解局部最优的思想，认识其局限
2. **分治** - 学会问题分解和合并，理解递归结构
3. **动态规划** - 掌握状态定义和转移

### 第二阶段：进阶（重点）
1. **回溯** - 掌握搜索树结构，学会有效剪枝
2. **分支限界** - 理解如何设计有效的界限估计

### 第三阶段：实践（应用）
1. 解决实际竞赛问题
2. 结合多个范式解决复杂问题
3. 代码优化和性能分析

## 选择决策指南

```
问题分析
  │
  ├─ 需要枚举所有解？
  │   ├─ 是 → 回溯（Backtracking）
  │   └─ 否 → 需要最优解？
  │       ├─ 是 → 动态规划（DP）或 贪心（Greedy）
  │       └─ 否 → 简化问题
  │
  └─ 可以分割成独立子问题？
      ├─ 是 → 分治（Divide and Conquer）
      └─ 否 → 其他方法
```

## 快速参考

| 范式 | 时间复杂度 | 空间 | 最优性 | 适用性 |
|------|----------|------|--------|--------|
| 贪心 | 多项式 | 低 | 有条件 | 有限 |
| 分治 | O(n log n)* | O(n) | 有 | 广泛 |
| 动态规划 | 多项式* | O(n²) | 有 | 广泛 |
| 回溯 | 指数 | O(n) | 有（枚举） | 有限 |
| 分支限界 | 指数* | O(n) | 有 | 优化问题 |

*取决于具体问题

## 学习建议

1. **理论与实践结合** - 先理解思想，再通过编码实践
2. **掌握复杂度分析** - 了解每个范式的时间和空间特性
3. **多语言学习** - 查看各文件夹中的多语言实现（Python、Java、C等）
4. **逐步深化** - 从简单问题到复杂问题
5. **问题变种** - 理解本质后，处理问题的各种变体
