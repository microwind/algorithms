# 搜索（Search）算法

## 概述

搜索算法用于在数据结构中查找特定元素或满足条件的元素。根据数据结构和效率要求的不同，存在多种搜索策略。

---

## 算法1：线性搜索（Linear Search）

### 描述
顺序扫描数组或列表中的每个元素，直到找到目标元素或遍历完整个数组。

### 关键特性
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)
- **优点**：简单，适用于小数据集或无序数组
- **缺点**：效率低，不适合大数据集

### 算法步骤
1. 从第一个元素开始
2. 逐个比较每个元素与目标值
3. 找到匹配则返回索引
4. 遍历完成仍未找到则返回 -1

### 应用场景
- 小规模数据搜索
- 链表搜索
- 无序数据搜索

---

## 算法2：二分搜索（Binary Search）

### 描述
在排序数组中通过不断将搜索范围折半，高效地查找元素。

### 关键特性
- **前置条件**：数组必须有序
- **时间复杂度**：O(log n)
- **空间复杂度**：O(1) 迭代版，O(log n) 递归版
- **优点**：高效，适合大数据集
- **缺点**：需要有序数据

### 算法步骤
1. 设置左右指针
2. 计算中间位置
3. 比较中间元素与目标值
4. 根据比较结果调整范围
5. 重复直到找到或范围为空

### 变种
- **递归实现**：利用分治思想
- **迭代实现**：避免递归开销
- **搜索范围**：第一个、最后一个匹配元素

---

## 算法3：深度优先搜索（DFS - Depth First Search）

### 描述
使用栈或递归在图或树中进行遍历，优先探索深度方向。

### 关键特性
- **数据结构**：适用于图和树
- **时间复杂度**：O(V + E) 其中 V 是顶点，E 是边
- **空间复杂度**：O(V)
- **遍历顺序**：优先探索深度方向

### 实现方式
1. **递归实现**：自然利用调用栈
2. **迭代实现**：显式使用栈结构

### 应用场景
- 拓扑排序
- 检测循环
- 路径查找
- 连通分量检测

### 算法步骤
1. 选择起始顶点，标记为已访问
2. 递归访问所有未访问的邻接顶点
3. 回溯到上一顶点
4. 重复直到所有顶点都被访问

---

## 算法4：广度优先搜索（BFS - Breadth First Search）

### 描述
使用队列在图或树中进行遍历，逐层探索。

### 关键特性
- **数据结构**：适用于图和树
- **时间复杂度**：O(V + E)
- **空间复杂度**：O(V)
- **遍历顺序**：逐层探索
- **特点**：找到最短路径

### 实现细节
- 使用队列 FIFO 结构
- 记录已访问顶点避免重复
- 按层级处理顶点

### 应用场景
- 最短路径查找
- 层序遍历
- 网络爬虫
- 社交网络分析

### 算法步骤
1. 将起始顶点加入队列
2. 循环处理队列中的顶点
3. 访问顶点，输出或处理数据
4. 将所有未访问的邻接顶点加入队列
5. 重复直到队列为空

---

## 性能对比

| 算法 | 时间复杂度 | 空间复杂度 | 前置条件 | 使用场景 |
|------|-----------|----------|---------|---------|
| 线性搜索 | O(n) | O(1) | 无 | 小数据集、无序数据 |
| 二分搜索 | O(log n) | O(1) | 有序数组 | 大数据集、有序数据 |
| DFS | O(V+E) | O(V) | 图/树 | 路径查找、拓扑排序 |
| BFS | O(V+E) | O(V) | 图/树 | 最短路径、层序遍历 |
