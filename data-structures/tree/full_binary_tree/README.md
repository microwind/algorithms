# 什么是双向链表？什么是满二叉树？

## 1. 双向链表（Doubly Linked List）
定义：双向链表是一种线性数据结构，链表中每个节点不仅包含数据元素，还包含两个指针，分别指向前驱节点和后继节点。相比单链表，双向链表可以在任意节点处方便地进行双向遍历和删除操作
特点：插入或删除节点时，只需修改相邻节点的两个指针即可；但由于维护了两个指针，内存开销和实现复杂度都高于单链表。

## 2. 满二叉树（Full Binary Tree）
定义：若一棵二叉树的每一层的节点数都达到最大值，则称其为满二叉树。若深度为 k，则节点总数应为 $2^k - 1$ 个
特点：除了最底层外，每个节点都有左右两个子节点；树的形状严格对称，适用于堆（Heap）等场景。
