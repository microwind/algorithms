# 入门指南

本目录用于新手快速建立整体认知，帮助你从"为什么学"到"怎么学"形成清晰路径。

## 📖 推荐阅读顺序

### 新手必读（必看）
1. **[学习路线](./learning-path.md)** - 📋 从入门到精通的完整学习规划
   - 分 5 个阶段的学习路线
   - 每个阶段的目标和内容
   - 学习建议和时间安排

2. **[什么是编程](./what-is-programming.md)** - 🤔 理解编程的本质
   - 编程核心是什么
   - 如何学好编程
   - 初学者必懂概念

3. **[算法思想](./algorithmic_thinking.md)** - 💡 10 大算法思想概览
   - 贪心、分治、动态规划等
   - 掌握思想，应用无穷

### 实践必备（动手前）
4. **[环境搭建指南](./environment-setup.md)** - 🔧 快速配置开发环境
   - Python、JavaScript、Java、Go、C/C++ 等环境搭建
   - 代码编辑器和 IDE 推荐
   - 第一个程序的编写和运行

5. **[推荐学习的编程语言](./recommand-learning-languages.md)** - 🎯 选择合适的入门语言
   - 各语言的优缺点对比
   - 根据目标选择语言

### 学习中遇到问题
6. **[常见问题解答 (FAQ)](./faq.md)** - ❓ 初学者常见问题汇总
   - 入门前的疑问
   - 学习过程中的问题
   - 面试和进阶问题

## 🎯 快速导航

| 你的情况 | 阅读建议 |
|---------|--------|
| **完全新手，不知道从哪开始** | 从 [学习路线](./learning-path.md) 开始，按顺序阅读 |

## ✅ 学习建议

1. **按顺序学习**：从学习路线开始，建立整体认知
2. **边学边练**：不要只读，要动手写代码
3. **遇到问题查 FAQ**：常见问题都有解答
4. **做好准备再行动**：环境搭建好了再开始编程
