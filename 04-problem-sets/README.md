## 问题分类

### 简单 (Easy)
- 基础数据结构操作
- 简单的字符串/数组处理
- 难度系数：⭐

### 中等 (Medium)
- 哈希表、动态规划
- 图的基础操作
- 难度系数：⭐⭐⭐

### 困难 (Hard)
- 复杂的字符串匹配
- 图论算法
- 难度系数：⭐⭐⭐⭐⭐

### 面试题 (Interview)
- 系统设计问题
- 并发编程
- 设计模式
