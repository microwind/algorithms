# 实际应用项目

用算法与数据结构解决真实世界的问题。

## 项目概览

每个项目展示如何将算法应用于生产环境中的实际问题。

### 项目列表

#### 1. [数组去重系统](./01-array-deduplication/)
**难度**: ⭐⭐ | **应用领域**: 数据统计、日志处理、用户分析

日志去重、用户统计、流量分析的核心技术。

**学习目标**:
- 掌握 Set/HashSet 数据结构
- 实现数据去重和统计
- 多语言实现（Python/Java/Go/JS）

**实际应用**:
- 日志系统中去重相同错误信息
- DAU/MAU 用户活跃度统计
- 网站独立IP访客统计

#### 2. [Hash签名验证系统](./02-hash-verification/)
**难度**: ⭐⭐⭐ | **应用领域**: 数据完整性、版本控制、内容去重

文件校验、数据防篡改、去重存储的基础。

**学习目标**:
- 理解 Hash 函数原理

**实际应用**:
- 文件下载完整性验证（MD5/SHA256）
- Git 内容寻址系统
- 数据库重复内容检测

#### 3. [字符串压缩系统](./03-string-compression/)
**难度**: ⭐⭐ | **应用领域**: 数据传输、存储优化、网络协议

数据压缩的经典算法和实际应用。

**学习目标**:
- 掌握 RLE、Gzip 等压缩算法
- 理解压缩与解压的原理
- 优化数据传输

**实际应用**:
- HTTP 传输中的 Gzip 压缩
- 日志文件压缩存储
- JSON 数据压缩减小响应体

#### 4. [一致哈希负载均衡](./04-consistent-hashing/)

#### 5. [布隆过滤器系统](./05-bloom-filter/)
**难度**: ⭐⭐⭐ | **应用领域**: 大数据处理、黑名单检测、缓存优化

大数据去重和快速检测的利器。

**学习目标**:
- 理解布隆过滤器原理
- 权衡空间和误判率
- 应用于实际场景

**实际应用**:
