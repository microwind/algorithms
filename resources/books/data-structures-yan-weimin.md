## 一、内容概要（Content Summary）

这本书是国内高校计算机专业使用最广泛的数据结构教材，没有之一。从 1992 年第一版出版至今，几乎每一届 CS 学生都绕不开这本书。它覆盖了数据结构课程的标准内容：线性结构（线性表、栈、队列、串）、非线性结构（树、图）、以及基于这些结构的查找和排序算法。

严蔚敏的写作风格是典型的中国工科教材风格——严谨、系统、逻辑清晰，但也相对干燥。书中用类 C 语言（不是严格的 C，而是伪代码风格的"算法语言"）描述算法，配合 ADT（Abstract Data Type，抽象数据类型）的形式化定义来组织每个数据结构的讨论。

这本书的核心价值在于体系完整。它把数据结构从最基本的线性表一路讲到图的遍历和最短路径，再到内外部排序，构建了一个完整的知识框架。对于需要参加考研或期末考试的学生来说，这本书的章节安排和知识点覆盖几乎就是考试大纲本身。

## 二、内容点评（Review）

### 这本书的亮点

- **体系完整**：数据结构课程需要覆盖的主题一个不缺，章节编排逻辑清晰，从简单到复杂层层递进
- **ADT 规范化**：用抽象数据类型统一描述每种数据结构的定义和操作，培养了一代人的抽象思维习惯
- **考试友好**：知识点与考研大纲高度吻合，章后习题覆盖常见考点
- **配套完善**：有配套习题集《数据结构题集（C语言版）》，提供大量练习
- **经典地位**：在国内 CS 教育体系中的地位类似 CLRS 在欧美的地位

### 不足之处

- **代码风格偏旧**：使用的"类 C 语言"算法描述与实际 C 语言有差异，初学者容易混淆
- **偏理论**：重定义和证明，缺少真实工程场景的应用示例
- **更新缓慢**：第 2 版（2012 年）相对第 1 版改动不大，部分内容未跟上现代实践
- **可读性一般**：行文偏学术，缺少直觉性的解释和图示引导
- **缺少现代数据结构**：跳表（Skip List）、布隆过滤器（Bloom Filter）、LSM-Tree 等工程常用结构未涉及

### 适合什么人看（Target Audience）

| 读者类型 | 推荐指数 | 说明 |
|---------|---------|------|
| 国内 CS 本科生 | ⭐⭐⭐⭐⭐ | 课程教材，应试必备 |
| 考研学生 | ⭐⭐⭐⭐⭐ | 408 统考数据结构部分的核心参考 |
| 有 C 语言基础的自学者 | ⭐⭐⭐⭐ | 体系完整，适合系统学习 |
| 工作多年想补基础的程序员 | ⭐⭐⭐ | 可以用，但有更现代的替代选择 |
| 零基础初学者 | ⭐⭐ | 需要先学 C 语言，且书本身不够友好 |

### 解决什么问题（Problems Solved）

- 系统建立**数据结构的知识体系**：从线性到非线性，从存储到操作，完整覆盖
- 理解**抽象数据类型**（ADT）的思想：学会用形式化方法定义和分析数据结构
- 掌握经典的**查找与排序算法**：包括它们的适用场景和性能特征
- 应对**考研和期末考试**：知识点覆盖与考试大纲高度一致

## 三、主要章节简介（Chapter Overview）

| 章节 | 标题 | 核心内容 |
|------|------|---------|
| 第 1 章 | 绪论（Introduction） | 数据结构基本概念、抽象数据类型、算法与算法分析 |
| 第 2 章 | 线性表（Linear List） | 顺序表、单链表、双向链表、循环链表、线性表的应用 |
| 第 3 章 | 栈和队列（Stack & Queue） | 栈的定义与实现、队列的定义与实现、递归、表达式求值 |
| 第 4 章 | 串（String） | 串的定义、KMP 模式匹配算法、串的存储结构 |
| 第 5 章 | 数组和广义表（Array & Generalized List） | 数组的存储、矩阵压缩存储、稀疏矩阵、广义表 |
| 第 6 章 | 树和二叉树（Tree & Binary Tree） | 二叉树遍历、线索二叉树、哈夫曼树与哈夫曼编码 |
| 第 7 章 | 图（Graph） | 图的存储（邻接矩阵、邻接表）、DFS、BFS、最小生成树、最短路径、拓扑排序 |
| 第 8 章 | 动态存储管理（Dynamic Storage） | 边界标识法、伙伴系统、垃圾回收 |
| 第 9 章 | 查找（Searching） | 顺序查找、折半查找、B 树、哈希表 |
| 第 10 章 | 内部排序（Internal Sorting） | 插入排序、交换排序、选择排序、归并排序、基数排序 |
| 第 11 章 | 外部排序（External Sorting） | 多路归并、置换-选择排序、最佳归并树 |
