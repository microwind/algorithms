# 机器学习

**作者：** 周志华  
**难度：** 进阶  
**侧重点：** 机器学习基础理论，中文经典教材  

## 书籍简介

《机器学习》（俗称"西瓜书"）是南京大学周志华教授编著的机器学习经典教材，被誉为国内机器学习领域的"圣经"。本书系统地介绍了机器学习的主要理论和算法，内容全面、讲解清晰，是中文世界最好的机器学习入门教材之一。

## 主要内容

### 第1章 绪论
介绍机器学习的基本概念、发展历程和应用领域。

### 第2章 模型评估与选择
- 经验误差与过拟合
- 评估方法（留出法、交叉验证、自助法）
- 性能度量（准确率、查准率、查全率、ROC曲线）
- 比较检验

### 第3章 线性模型
- 线性回归
- 对数几率回归（逻辑回归）
- 线性判别分析（LDA）
- 多分类学习
- 类别不平衡问题

### 第4章 决策树
- 基本流程

- 剪枝处理
- 连续与缺失值
- 多变量决策树

### 第5章 神经网络
- 神经元模型
- 感知机与多层网络
- 误差逆传播算法（BP）
- 常见神经网络模型（RBF、Elman等）

### 第6章 支持向量机
- 间隔与支持向量
- 对偶问题
- 核函数
- 软间隔与正则化
- 支持向量回归

### 第7章 贝叶斯分类器
- 贝叶斯定理
- 极大似然估计
- 朴素贝叶斯分类器
- 半朴素贝叶斯
- 贝叶斯网络

### 第8章 集成学习
- 个体与集成
- Boosting（AdaBoost、GBDT）
- Bagging与随机森林
- 结合策略

### 第9章 聚类
- 聚类任务
- 性能度量
- 距离计算
- 原型聚类（k-means）
- 密度聚类（DBSCAN）
- 层次聚类

### 第10章 降维与度量学习
- k近邻学习
- 低维嵌入
- 主成分分析（PCA）
- 核化线性降维
- 流形学习
- 度量学习

### 第11章 特征选择与稀疏学习
- 子集搜索与评价
- 过滤式、包裹式、嵌入式方法
- 压缩感知

### 第12章 计算学习理论
- 基础知识
- PAC学习
- 有限假设空间
- VC维
- Rademacher复杂度

### 第13章 半监督学习
- 未标记样本的作用
- 生成式方法
- 半监督SVM
- 图半监督学习
- 基于分歧的方法

### 第14章 概率图模型
- 隐马尔可夫模型
- 马尔可夫随机场
- 条件随机场
- 精确推断
- 近似推断

### 第15章 规则学习
- 基本概念
- 序列覆盖
- 剪枝优化
- 归纳逻辑程序设计

### 第16章 强化学习
- 任务与奖赏
- k-摇臂赌博机
- 有模型学习
- 免模型学习
- 值函数近似
- 模仿学习

## 特点

1. **系统性强**：涵盖了机器学习的主要理论和算法，从基础到高级
2. **数学严谨**：注重数学推导和理论分析，适合想深入理解的读者
3. **中文友好**：使用中文编写，讲解清晰，适合中文读者
4. **习题丰富**：每章都有习题，有助于巩固知识

## 适用人群

- 有一定数学基础的本科生、研究生
- 想系统学习机器学习理论的工程师
- 准备从事AI研究的学生和研究人员

## 学习建议

1. **数学基础**：需要掌握线性代数、概率论、微积分等数学知识
2. **循序渐进**：按章节顺序学习，不要跳跃
3. **动手实践**：结合代码实现，加深理解
4. **参考其他资源**：可以配合《统计学习方法》等书籍一起学习

## 总结

《机器学习》是一本优秀的中文机器学习教材，适合想系统学习机器学习理论的读者。虽然数学要求较高，但讲解清晰，是中文世界机器学习学习的首选教材之一。
