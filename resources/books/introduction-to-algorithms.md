## 一、内容概要（Content Summary）

《算法导论》（业界通常简称 CLRS，取四位作者姓氏首字母）是算法领域公认的标准参考书。自 1990 年第一版问世以来，它被全球数百所大学采用为教材，也是技术面试准备、算法竞赛训练和学术研究中被引用最多的算法书籍之一。

这本书采用伪代码描述算法，不依赖任何特定编程语言。每个算法都配有严格的正确性证明和复杂度分析，大量运用数学工具（求和、递归式、概率论、摊还分析等）。第 4 版新增了机器学习算法章节，也更新了多个已有章节的内容。

CLRS 的覆盖面极广：从基础的排序和数据结构，到图算法、动态规划、贪心算法，再到数论、字符串匹配、计算几何、NP 完全性和近似算法。它的目标不是"教你写代码"，而是让你**理解算法为什么正确、为什么高效**。

需要明确的一点是：这本书不适合作为算法学习的第一本书。它的定位是**参考手册**，适合在有一定基础后，按需查阅特定主题。从头到尾读完这本书的人不多，也没有必要。

## 二、内容点评（Review）

### 这本书的亮点

- **覆盖面无出其右**：从排序到 NP 完全性，几乎涵盖了本科和研究生阶段需要掌握的所有算法主题
- **数学严谨**：每个算法都有完整的正确性证明和复杂度分析，不只是给结论，更展示推导过程
- **伪代码清晰**：算法描述不绑定语言，便于理解核心逻辑，也便于用任何语言实现
- **习题丰富**：每章都有大量习题和思考题（Problems），涵盖不同难度层次
- **第 4 版更新显著**：新增机器学习算法（梯度下降、线性分类等），删除了斐波那契堆和 van Emde Boas 树等较冷门的内容，更贴近现代需求
- **权威性**：学术论文和技术讨论中引用算法时，CLRS 是事实上的标准参考

### 不足之处

- **入门门槛高**：数学符号密集，没有离散数学基础会很吃力
- **实践性不足**：伪代码无法直接运行，缺少工程实现的讨论
- **篇幅过大**：1300+ 页的体量对大多数读者来说过于庞大
- **缺乏直觉引导**：偏重形式化证明，对"为什么要用这个算法"的直觉解释较少
- **部分章节深度不均**：某些高级主题（如线性规划）的篇幅有限，不如专门书籍深入

### 适合什么人看（Target Audience）

| 读者类型 | 推荐指数 | 说明 |
|---------|---------|------|
| CS 研究生 | ⭐⭐⭐⭐⭐ | 核心参考书，课程和研究都需要 |
| 算法竞赛选手 | ⭐⭐⭐⭐⭐ | 经典算法的权威来源 |
| 准备技术面试 | ⭐⭐⭐⭐ | 按主题查阅，不需要通读 |
| CS 本科高年级 | ⭐⭐⭐⭐ | 配合课程使用效果好 |
| 有经验的工程师 | ⭐⭐⭐ | 作为案头参考书，按需查阅 |
| 初学者 | ⭐⭐ | 不建议作为第一本算法书 |

### 解决什么问题（Problems Solved）

- 需要**查阅某个算法的标准定义和分析**：CLRS 就是算法的"字典"
- 想**理解算法背后的数学原理**：为什么快速排序平均 O(n log n)，怎么证明
- 准备**算法课程、面试或竞赛**：系统掌握经典算法和数据结构
- 需要了解**高级算法主题**：NP 完全性、近似算法、数论算法等

## 三、主要章节简介（Chapter Overview）

全书分为 8 个部分（Part），共 35 章：

| 部分 | 章节 | 核心内容 |
|------|------|---------|
| Part I: Foundations | Ch 1-5 | 算法的角色、增长量级、分治策略、概率分析与随机化算法 |
| Part II: Sorting and Order Statistics | Ch 6-9 | 堆排序、快速排序、线性时间排序、中位数与顺序统计量 |
| Part III: Data Structures | Ch 10-14 | 基本数据结构、散列表、二叉搜索树、红黑树、数据结构的扩展 |
| Part IV: Advanced Design and Analysis | Ch 15-17 | 动态规划、贪心算法、摊还分析 |
| Part V: Advanced Data Structures | Ch 18-20 | B 树、不相交集合的数据结构、可合并堆 |
| Part VI: Graph Algorithms | Ch 21-26 | BFS、DFS、拓扑排序、最小生成树、单源/全源最短路径、最大流、二部图匹配 |
| Part VII: Selected Topics | Ch 27-34 | 多线程算法、矩阵运算、线性规划、多项式与 FFT、数论算法、字符串匹配、机器学习算法（第 4 版新增）、NP 完全性、近似算法 |
| Part VIII: Appendices | A-D | 求和、集合论、计数与概率、矩阵 |
