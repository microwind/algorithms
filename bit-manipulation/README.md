# 位操作算法完整教学资源

## 概述

位操作（Bit Manipulation）是直接对二进制位进行操作的算法。位运算是计算机底层的基础操作，具有极高的执行效率，常用于优化算法性能、实现特殊的数据结构和解决特定问题。

位运算在算法设计中具有重要地位，能够以O(1)的时间复杂度完成很多复杂的操作，是程序员工具箱中的重要武器。

### 位操作的三个关键要素

位操作算法通常包含：
1. **位运算符**：AND (&)、OR (|)、XOR (^)、NOT (~)、左移 (<<)、右移 (>>)
2. **位操作技巧**：n & (n-1) 清除最低位的1、n & -n 获取最低位的1
3. **应用场景**：算法优化、状态压缩、权限管理等

## 核心算法分类

### 1. 基础位操作技巧
- **n & (n-1)**：清除最低位的1
- **n & -n**：获取最低位的1
- **交换两个数**：使用XOR交换，无需临时变量
- **位运算替代乘除**：左移相当于乘2，右移相当于除2

### 2. 计数1位 (count-bits/)
- **Kernighan算法**：n & (n-1) 逐步清除最低位的1
- **并行计数**：分治法思想，并行计算1的个数
- **查表法**：预计算8位或16位的1的个数
- **应用**：错误检测、网络协议、图像处理

### 3. 2的幂检测 (power-of-two/)
- **检测方法**：n & (n-1) == 0
- **找下一个2的幂**：位操作技巧
- **应用**：内存分配对齐、数据结构设计

### 4. 位反转 (reverse-bits/)
- **逐位迭代**：从最低位到最高位依次处理
- **分治法**：先反转16位，再反转8位，最后反转1位
- **查表法**：预计算8位的反转结果
- **应用**：加密算法、数据压缩

### 5. 找出单独数字 (single-number/)
- **XOR性质**：a ^ a = 0, a ^ 0 = a
- **算法思想**：所有出现两次的数字通过XOR运算会相互抵消
- **应用**：数据去重、错误检测、密码学

### 6. 最大XOR对 (max-xor-pair/)
- **蛮力法**：O(n²) 检查所有可能的数对
- **Trie树**：O(n) 构建二进制前缀树，贪心查找最大XOR
- **位贪心**：从高位到低位逐步构建最大XOR
- **应用**：数组配对问题、最大差异计算

## 位操作基础

### 基本位运算符

- **AND (&)**：对应位都为1时结果为1
- **OR (|)**：对应位有一个为1时结果为1
- **XOR (^)**：对应位不同时结果为1
- **NOT (~)**：按位取反
- **左移 (<<)**：向左移动位，右边补0
- **右移 (>>)**：向右移动位，左边补符号位

### 常用位操作技巧

- **n & (n-1)**：清除最低位的1
- **n & -n**：获取最低位的1
- **n ^ (n >> 1)**：格雷码转换
- **交换两个数**：a ^= b; b ^= a; a ^= b

## 常见的位操作算法

### 找出单独数字 (single-number/)
在数组中找到只出现一次的数字，其他数字都出现两次。利用XOR的性质：a ^ a = 0, a ^ 0 = a。

**核心思想**：
- 所有出现两次的数字通过XOR运算会相互抵消
- 最终结果就是只出现一次的数字

**应用**：
- 数据去重
- 错误检测
- 密码学

### 2的幂检测 (power-of-two/)
检查数字是否为2的幂。利用性质：2的幂的二进制表示中只有一个1。

**核心思想**：
- n & (n-1) == 0 可以判断是否为2的幂
- 通过位运算可以快速计算相关操作

**应用**：
- 内存分配对齐
- 数据结构设计
- 算法优化

### 计数1位 (count-bits/)
计算二进制表示中的1位数（哈明权重）。多种实现方法：Kernighan、查表、并行计数。

**核心思想**：
- Kernighan算法：n & (n-1) 清除最低位的1
- 查表法：预计算8位或16位的1的个数
- 并行计数：利用位运算并行计算

**应用**：
- 错误检测和纠正
- 网络协议
- 图像处理

### 位反转 (reverse-bits/)
反转32位整数中的位顺序。多种实现方法：迭代、分治、查表。

**核心思想**：
- 逐位处理：从最低位到最高位依次处理
- 分治法：先反转16位，再反转8位，最后反转1位
- 查表法：预计算8位的反转结果

**应用**：
- 加密算法
- 数据压缩
- 网络协议

### 最大XOR对 (max-xor-pair/)
从数组中的任何对找到最大XOR值。多种实现方法：蛮力O(n²)、Trie树O(n)。

**核心思想**：
- 蛮力法：检查所有可能的数对
- Trie树：构建二进制前缀树，贪心查找最大XOR
- 位贪心：从高位到低位逐步构建最大XOR

**应用**：
- 数组配对问题
- 最大差异计算
- 游戏策略

## 特点

### 优点
- 执行效率高：位运算通常是O(1)时间复杂度
- 空间占用小：不需要额外存储空间
- 硬件友好：直接对应CPU指令
- 算法优化：可以替代某些数学运算

### 缺点
- 可读性差：位操作代码不易理解
- 可移植性：不同平台可能有差异
- 调试困难：位操作问题难以定位
- 限制条件：受限于整数位数

## 简单例子

### Python 示例 - 找出单独数字
```python
def single_number(nums):
    """使用XOR找出只出现一次的数字"""
    result = 0
    for num in nums:
        result ^= num
    return result

print(single_number([4, 1, 2, 1, 2]))  # 输出: 4
```

### C 语言示例 - 2的幂检测
```c
#include <stdio.h>
#include <stdbool.h>

bool isPowerOfTwo(int n) {
    if (n <= 0) return false;
    return (n & (n - 1)) == 0;
}

int main() {
    printf("8 is power of two: %d\n", isPowerOfTwo(8));    // 1 (true)
    printf("6 is power of two: %d\n", isPowerOfTwo(6));    // 0 (false)
    return 0;
}
```

### Java 示例 - 计数1位
```java
public class BitManipulation {
    // Kernighan算法
    public static int countBits(int n) {
        int count = 0;
        while (n != 0) {
            n &= (n - 1);
            count++;
        }
        return count;
    }

    public static void main(String[] args) {
        System.out.println(countBits(13));  // 输出: 3
    }
}
```

### Go 示例 - 位反转
```go
package main

import "fmt"

func reverseBits(n uint32) uint32 {
    var result uint32 = 0
    for i := 0; i < 32; i++ {
        result = (result << 1) | (n & 1)
        n >>= 1
    }
    return result
}

func main() {
    fmt.Println(reverseBits(43261596))  // 输出: 964176192
}
```

## 优化技巧

### 1. 查表法
预计算常用结果，避免重复计算：
```python
# 预计算256个8位数的1的个数
BIT_COUNTS = [bin(i).count('1') for i in range(256)]

def count_bits_lookup(n):
    count = 0
    while n:
        count += BIT_COUNTS[n & 0xFF]
        n >>= 8
    return count
```

### 2. 并行计数
利用位运算并行计算：
```c
int parallelCount(int n) {
    n = n - ((n >> 1) & 0x55555555);
    n = (n & 0x33333333) + ((n >> 2) & 0x33333333);
    n = (n + (n >> 4)) & 0x0F0F0F0F;
    n = n + (n >> 8);
    n = n + (n >> 16);
    return n & 0x3F;
}
```

### 3. 位运算替代数学运算
```c
// 左移替代乘法
x = x << 3;  // 相当于 x = x * 8

// 右移替代除法
x = x >> 2;  // 相当于 x = x / 4
```

## 常见陷阱

1. 忽略符号位：有符号数的右移会保留符号位
2. 优先级错误：位运算优先级低于比较运算符
3. 整数溢出：左移可能导致溢出
4. 平台差异：不同平台的整数位数可能不同
5. 可读性问题：复杂的位运算难以理解和维护
