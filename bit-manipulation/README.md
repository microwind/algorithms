# 【位运算算法详解】Java/Go/Python/JS/C不同语言实现

## 说明

位运算（Bit Manipulation）是直接对二进制位进行操作的算法。位运算是计算机底层的基础操作，具有极高的执行效率，常用于优化算法性能、实现特殊的数据结构和解决特定问题。

位运算在算法设计中具有重要地位，能够以O(1)的时间复杂度完成很多复杂的操作，是程序员工具箱中的重要武器。

> **生活类比**：就像电灯开关，每个开关只有开（1）和关（0）两种状态。通过巧妙地组合这些开关，可以表示复杂的信息，就像用二进制位表示数字、字符和各种状态。

**二进制位结构示意**：
```
32位整数在内存中的表示 (以数字 13 为例):
┌────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┐
│ 31 │ 30 │ 29 │ .. │  5 │  4 │  3 │  2 │  1 │  0 │ ← 位索引 (从右到左)
├────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┤
│  0 │  0 │  0 │ .. │  0 │  1 │  1 │  0 │  1 │  0 │ ← 二进制值
└────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┘
                                       ↑
                                   8+4+1=13

位权值示意:
位索引:  7   6   5   4   3   2   1   0
        ↓   ↓   ↓   ↓   ↓   ↓   ↓   ↓
       128  64  32  16   8   4   2   1  ← 2的幂次
        
示例: 13 = 8 + 4 + 1 = 2³ + 2² + 2⁰ = 0b00001101
```

## 2. 位操作基础

### 2.1 基本位运算符

**位运算符示意表**：
```
┌─────────┬──────────┬────────────────────────────────────────────────────────────┐
│ 运算符   │   示例    │                         说明                                │
├─────────┼──────────┼────────────────────────────────────────────────────────────┤
│ AND (&) │ a & b    │ 两位都为1时结果为1                                            │
│         │  1010    │  1010 (10)                                                 │
│         │& 1100    │& 1100 (12)                                                 │
│         │  ----    │  ----                                                      │
│         │  1000    │  1000 (8)  ← 结果                                           │
├─────────┼──────────┼────────────────────────────────────────────────────────────┤
│ OR (|)  │ a | b    │ 有一位为1时结果为1                                            │
│         │  1010    │  1010 (10)                                                 │
│         │| 1100    │| 1100 (12)                                                 │
│         │  ----    │  ----                                                      │
│         │  1110    │  1110 (14) ← 结果                                           │
├─────────┼──────────┼────────────────────────────────────────────────────────────┤
│ XOR (^) │ a ^ b    │ 两位不同时结果为1                                             │
│         │  1010    │  1010 (10)                                                 │
│         │^ 1100    │^ 1100 (12)                                                 │
│         │  ----    │  ----                                                      │
│         │  0110    │  0110 (6)  ← 结果                                           │
├─────────┼──────────┼────────────────────────────────────────────────────────────┤
│ NOT (~) │ ~a       │ 按位取反 (0变1, 1变0)                                        │
│         │ ~000...1010 │ ~00000000000000000000000000001010 (10)                  │
│         │  ↓↓↓↓↓↓    │  ↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓                        │
│         │  111...0101 │  11111111111111111111111111110101 (-11)                 │
├─────────┼──────────┼────────────────────────────────────────────────────────────┤
│ 左移(<<)│ a << n   │ 向左移动n位, 右边补0 (相当于 ×2ⁿ)                              │
│         │  000011  │  000011 (3)                                                │
│         │ << 2     │  << 2                                                      │
│         │  ↓↓↓↓↓↓  │  ↓↓↓↓↓↓                                                    │
│         │  001100  │  001100 (12) ← 3 × 2² = 12                                 │
├─────────┼──────────┼────────────────────────────────────────────────────────────┤
│ 右移(>>)│ a >> n   │ 向右移动n位, 左边补符号位 (相当于 ÷2ⁿ)                          │
│         │  1100    │  00001100 (12)                                             │
│         │ >> 2     │  >> 2                                                      │
│         │  ↓↓↓↓↓↓  │  ↓↓↓↓↓↓                                                    │
│         │  0011    │  00000011 (3) ← 12 ÷ 2² = 3                                │
└─────────┴──────────┴────────────────────────────────────────────────────────────┘
```

- **AND (&)**：对应位都为1时结果为1
- **OR (|)**：对应位有一个为1时结果为1
- **XOR (^)**：对应位不同时结果为1
- **NOT (~)**：按位取反
- **左移 (<<)**：向左移动位，右边补0
- **右移 (>>)**：向右移动位，左边补符号位
- **无符号右移 (>>>)**：向右移动位，左边补0

### 2.2 常用位操作技巧

**技巧图解**：
```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 技巧1: n & (n-1) - 清除最低位的1                                                │
├──────────────────────────────────────────────────────────────────────────────┤
│ n   = 0b101100 (44)                                                          │
│ n-1 = 0b101011 (43)                                                          │
│     & --------                                                               │
│       0b101000 (40) ← 最低位的1被清除                                          │
│          ↑                                                                   │
│       这一位从1变成0                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ 技巧2: n & -n - 获取最低位的1 (isolation)                                       │
├──────────────────────────────────────────────────────────────────────────────┤
│ n   = 0b101100 (44)                                                          │
│ -n  = 0b010100 (补码表示)                                                     │
│     & --------                                                               │
│       0b000100 (4)  ← 只保留最低位的1                                          │
│          ↑                                                                   │
│       最低位的1被隔离出来                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ 技巧3: 交换两个数 (不使用临时变量)                                                │
├──────────────────────────────────────────────────────────────────────────────┤
│ a = 5 (0b101), b = 3 (0b011)                                                 │
│                                                                              │
│ 步骤1: a = a ^ b                                                              │
│ a = 101 ^ 011 = 110 (6)                                                      │
│                                                                              │
│ 步骤2: b = b ^ a                                                              │
│ b = 011 ^ 110 = 101 (5)  ← b变成原来的a                                        │
│                                                                              │
│ 步骤3: a = a ^ b                                                              │
│ a = 110 ^ 101 = 011 (3)  ← a变成原来的b                                        │
│                                                                              │
│ 结果: a = 3, b = 5  成功交换!                                                  │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **n & (n-1)**：清除最低位的1
- **n & -n**：获取最低位的1
- **n ^ (n >> 1)**：格雷码转换
- **交换两个数**：a ^= b; b ^= a; a ^= b

## 3. 常见的位操作算法

### 3.1 找出单独数字（Single Number）
**概述**：
- 在数组中找到只出现一次的数字，其他数字都出现两次。
- 利用XOR的性质：a ^ a = 0, a ^ 0 = a。

**算法过程示意**：
```
数组: [4, 1, 2, 1, 2]  (4只出现1次, 其他出现2次)

二进制表示:
4 = 100
1 = 001
2 = 010

XOR运算过程 (相同为0, 不同为1):
┌─────────┬─────────┬─────────┬─────────────────────┐
│  步骤    │  当前值  │  下一值  │     XOR结果         │
├─────────┼─────────┼─────────┼─────────────────────┤
│ 初始    │   0     │    -    │     0 (000)         │
│ 第1步   │   0     │   4     │ 0^4=4 (100)         │
│ 第2步   │   4     │   1     │ 4^1=5 (101)         │
│ 第3步   │   5     │   2     │ 5^2=7 (111)         │
│ 第4步   │   7     │   1     │ 7^1=6 (110) ← 1^1=0 │
│ 第5步   │   6     │   2     │ 6^2=4 (100) ← 2^2=0 │
└─────────┴─────────┴─────────┴─────────────────────┘

结果: 4 (100)  ← 只出现一次的数字

原理说明:
- 出现两次的数字: a ^ a = 0 (相互抵消)
- 只出现一次的数字: 0 ^ a = a (保留下来)
- 所有成对数字都抵消后, 只剩单独的数字
```

**核心思想**：
- 所有出现两次的数字通过XOR运算会相互抵消
- 最终结果就是只出现一次的数字

**应用**：
- 数据去重
- 错误检测
- 密码学

### 3.2 2的幂检测（Power of Two）
**概述**：
- 检查数字是否为2的幂，计算指数，找下一个2的幂。
- 利用性质：2的幂的二进制表示中只有一个1。

**算法过程示意**：
```
2的幂的二进制特征:
2⁰ = 1  = 0b0001  (只有1个1)
2¹ = 2  = 0b0010  (只有1个1)
2² = 4  = 0b0100  (只有1个1)
2³ = 8  = 0b1000  (只有1个1)

检测方法 - n & (n-1):
┌─────────────────────────────────────────────────────────┐
│ 以 n = 8 (2的幂) 为例:                                    │
│ n     = 0b1000 (8)                                      │
│ n-1   = 0b0111 (7)                                      │
│ n&(n-1)= 0b0000 (0)  ← 结果为0, 说明是2的幂                │
│                                                         │
│ 以 n = 6 (非2的幂) 为例:                                  │
│ n     = 0b0110 (6)                                      │
│ n-1   = 0b0101 (5)                                      │
│ n&(n-1)= 0b0100 (4)  ← 结果非0, 说明不是2的幂              │
└─────────────────────────────────────────────────────────┘

找下一个2的幂:
┌─────────────────────────────────────────────────────────┐
│ 以 n = 10 为例:                                          │
│ n      = 0b00001010 (10)                                │
│ n-1    = 0b00001001                                     │
│ n |= n-1 → 0b00001011                                   │
│ n >>= 1  → 0b00000101  (继续传播1到高位)                  │
│ 最终: n = 0b00010000 (16)  ← 下一个2的幂                  │
│                                                         │
│ 算法: 将最高位的1后面的所有位都变成1, 然后加1                 │
│       或者右移直到只剩下最高位的1                           │
└─────────────────────────────────────────────────────────┘
```

**核心思想**：
- n & (n-1) == 0 可以判断是否为2的幂
- 通过位运算可以快速计算相关操作

**应用**：
- 内存分配对齐
- 数据结构设计
- 算法优化

### 3.3 计数1位（Count Bits）
**概述**：
- 计算二进制表示中的1位数（哈明权重）。
- 多种实现方法：循环、Kernighan、查表、并行计数。

**算法过程示意**：
```
Kernighan算法 - 逐步清除最低位的1:
┌──────────────────────────────────────────────────────────┐
│ 以 n = 13 (0b1101) 为例, 统计1的个数:                       │
│                                                          │
│ 初始: n = 1101, count = 0                                 │
│                                                          │
│ 第1次: n & (n-1) = 1101 & 1100 = 1100 (12)                │
│        count = 1, 清除了最低位的1                          │
│                                                          │
│ 第2次: n & (n-1) = 1100 & 1011 = 1000 (8)                │
│        count = 2, 再次清除最低位的1                        │
│                                                          │
│ 第3次: n & (n-1) = 1000 & 0111 = 0000 (0)                │
│        count = 3, 清除最后一个1, n变为0                    │
│                                                          │
│ 结果: 共有3个1                                            │
│                                                          │
│ 原理: 每次 n & (n-1) 都会清除最低位的1, 循环次数=1的个数       │
└──────────────────────────────────────────────────────────┘

并行计数法 (分治法思想):
┌──────────────────────────────────────────────────────────┐
│ 对32位整数, 分阶段计算:                                     │
│                                                          │
│ 第1步 - 每2位计算1的个数:                                   │
│ n = n & 0x55555555 + (n >> 1) & 0x55555555               │
│ 00 01 10 11 → 00 01 01 10 (每2位表示原来的1的个数)          │
│                                                          │
│ 第2步 - 每4位计算1的个数:                                   │
│ n = n & 0x33333333 + (n >> 2) & 0x33333333               │
│                                                          │
│ 第3步 - 每8位计算1的个数:                                   │
│ n = n & 0x0F0F0F0F + (n >> 4) & 0x0F0F0F0F               │
│                                                          │
│ 第4步 - 每16位计算1的个数:                                  │
│ n = n & 0x00FF00FF + (n >> 8) & 0x00FF00FF               │
│                                                          │
│ 第5步 - 合并结果:                                          │
│ n = n & 0x0000FFFF + (n >> 16) & 0x0000FFFF              │
│                                                          │
│ 时间复杂度: O(log n) 次位运算, 但常数很小, 实际很快            │
└──────────────────────────────────────────────────────────┘
```

**核心思想**：
- Kernighan算法：n & (n-1) 清除最低位的1
- 查表法：预计算8位或16位的1的个数
- 并行计数：利用位运算并行计算

**应用**：
- 错误检测和纠正
- 网络协议
- 图像处理

**实现文件**：
- `count_bits.py`
- `count_bits.c`
- `CountBits.java`
- `count_bits.go`
- `count_bits.js`

### 3.4 位反转（Reverse Bits）
**概述**：
- 反转32位整数中的位顺序。
- 多种实现方法：迭代、手动操作、逐字节、查表。

**算法过程示意**：
```
逐字节反转法:
┌──────────────────────────────────────────────────────────┐
│ 输入: 0b 11010011 00101101 10101010 11110000              │
│        │ 字节0  │ 字节1  │ 字节2  │ 字节3                   │
│        ↓        ↓        ↓        ↓                       │
│       查表     查表     查表     查表                        │
│        ↓        ↓        ↓        ↓                       │
│      11001011 10110100 01010101 00001111                  │
│                                                           │
│ 组合: 00001111 01010101 10110100 11001011 (字节逆序)        │
│                                                           │
│ 查表示例 (8位反转表 reverse_table[256]):                    │
│ reverse_table[0b11010011] = 0b11001011                    │
│ reverse_table[0b00101101] = 0b10110100                    │
│ ...                                                       │
└──────────────────────────────────────────────────────────┘

逐位迭代法:
┌──────────────────────────────────────────────────────────┐
│ 输入: n = 0b1101 (13, 假设4位, 实际32位)                    │
│                                                          │
│ 初始: result = 0000                                       │
│                                                          │
│ 第1次:                                                    │
│   n的最低位 = 1                                           │
│   result = (result << 1) | 1 = 0001                      │
│   n >>= 1 → n = 0110                                     │
│                                                          │
│ 第2次:                                                    │
│   n的最低位 = 0                                           │
│   result = (result << 1) | 0 = 0010                      │
│   n >>= 1 → n = 0011                                     │
│                                                          │
│ 第3次:                                                    │
│   n的最低位 = 1                                           │
│   result = (result << 1) | 1 = 0101                      │
│   n >>= 1 → n = 0001                                     │
│                                                          │
│ 第4次:                                                   │
│   n的最低位 = 1                                           │
│   result = (result << 1) | 1 = 1011                      │
│   n >>= 1 → n = 0000 (结束)                              │
│                                                          │
│ 结果: 0b1011 (11)  ← 原数13的位反转                         │
└──────────────────────────────────────────────────────────┘
```

**核心思想**：
- 逐位处理：从最低位到最高位依次处理
- 分治法：先反转16位，再反转8位，最后反转1位
- 查表法：预计算8位的反转结果

**应用**：
- 加密算法
- 数据压缩
- 网络协议

### 3.5 最大XOR对（Max XOR Pair）
**概述**：
- 从数组中的任何对找到最大XOR值。
- 多种实现方法：蛮力O(n²)、Trie树O(n)、贪心O(n)。

**Trie树算法示意**：
```
构建Trie树 (以数组 [3, 10, 5, 25, 2, 8] 为例):

二进制表示 (5位):
 3 = 00011
10 = 01010
 5 = 00101
25 = 11001
 2 = 00010
 8 = 01000

Trie树结构 (从高位到低位):
                    root
                   /    \
                  0      1
                 / \      \
                0   1      1
               /   / \      \
              0   0   1      0
             ...

查找最大XOR:
┌──────────────────────────────────────────────────────────┐
│ 对于数字 25 = 11001:                                      │
│                                                          │
│ 位4 (最高位): 1 → 尽量找0分支 (使XOR的该位为1)               │
│   找到0分支: 路径对应 01010 (10)                           │
│   当前XOR: 11001 ^ 01010 = 10011 (19)                    │
│                                                          │
│ 位3: 1 → 找0分支                                          │
│   ...继续贪心选择                                         │
│                                                          │
│ 最终结果: 25 ^ 5 = 11001 ^ 00101 = 11100 (28)             │
│ 这是数组中能获得的最大XOR值                                  │
│                                                          │
│ 贪心策略: 从最高位开始, 尽量选择相反的位,                      │
│          使XOR结果的当前位为1                               │
└──────────────────────────────────────────────────────────┘

蛮力法对比 (O(n²)):
┌──────────────────────────────────────────────────────────┐
│ 检查所有数对:                                              │
│ 3^10=9, 3^5=6, 3^25=26, 3^2=1, 3^8=11                    │
│ 10^5=15, 10^25=19, 10^2=8, 10^8=2                        │
│ 5^25=28 ✓ 最大, 5^2=7, 5^8=13                             │
│ 25^2=27, 25^8=17, 2^8=10                                 │
│                                                          │
│ 最大XOR = 28 (来自数对 5 和 25)                            │
└──────────────────────────────────────────────────────────┘
```

**核心思想**：
- 蛮力法：检查所有可能的数对
- Trie树：构建二进制前缀树，贪心查找最大XOR
- 位贪心：从高位到低位逐步构建最大XOR

**应用**：
- 数组配对问题
- 最大差异计算
- 游戏策略

**实现文件**：
- `max_xor_pair.py`
- `max_xor_pair.c`
- `MaxXorPair.java`
- `max_xor_pair.go`
- `max_xor_pair.js`
- `max_xor_pair.rs`

## 5. 性能特点

### 5.1 时间复杂度
- **基本位运算**：O(1)
- **位计数**：O(log n) 到 O(1)
- **位反转**：O(log n)
- **最大XOR对**：O(n²) 到 O(n)

### 5.2 空间复杂度
- **原地操作**：O(1)
- **查表法**：O(1) 到 O(256)
- **Trie树**：O(n)

- **JavaScript**：现代ES6+语法，32位处理
- **Python**：简洁语法，多种实现
