# 图（Graph）算法概述

## 1. 什么是图？
图（Graph）是一种由**顶点（Vertex）**和**边（Edge）**组成的数据结构，用于表示对象之间的多对多关系。图论是数学的一个重要分支，在计算机科学、网络分析、运筹学等领域有广泛应用。

**图的结构示意**：
```
无向图示例:

    ┌───┐       ┌───┐
    │ A │───────│ B │
    └─┬─┘   1   └─┬─┘
      │           │
   2  │    ┌───┐  │ 3
      └────│ C │──┘
           └─┬─┘
             │ 4
      ┌──────┴──────┐
      │ 5           │ 6
   ┌──┴──┐       ┌──┴──┐
   │  D  │───────│  E  │
   └─────┘   7   └─────┘

图的组成:
• 顶点集 V = {A, B, C, D, E}
• 边集 E = {(A,B,1), (A,C,2), (B,C,3), (C,D,4), (C,E,5), (D,E,7)}
• 边上的数字表示权重(Weighted Graph)

有向图示例:

    ┌───┐ ───→ ┌───┐
    │ A │  1   │ B │
    └─┬─┘ ←─── └─┬─┘
      ↓ 2       ↓ 3
    ┌───┐ ───→ ┌───┐
    │ C │  4   │ D │
    └───┘       └───┘

边有方向: A→B, A→C, B→D, C→D
```

## 2. 图的基本特性

### 2.1 图的分类
```
图的分类体系:

图(Graph)
├── 按边是否有方向
│   ├── 无向图 (Undirected)
│   │   └── 边无方向，(u,v) = (v,u)
│   │
│   └── 有向图 (Directed)
│       └── 边有方向，(u,v) ≠ (v,u)
│
├── 按边是否有权重
│   ├── 无权图 (Unweighted)
│   │   └── 所有边权重相同(通常为1)
│   │
│   └── 加权图 (Weighted)
│       └── 边有不同权重值
│
├── 按边的连接特性
│   ├── 简单图 (Simple)
│   │   └── 无自环、无重边
│   │
│   ├── 多重图 (Multigraph)
│   │   └── 允许重边
│   │
│   └── 完全图 (Complete)
│       └── 每对顶点间都有边
│
└── 按稀疏程度
    ├── 稀疏图 (Sparse)
    │   └── E ≈ O(V)
    │
    └── 稠密图 (Dense)
        └── E ≈ O(V²)
```

### 2.2 图的表示方式

**邻接矩阵 (Adjacency Matrix)**：
```
图的邻接矩阵表示:

对于5个顶点的无向加权图:

      A   B   C   D   E
   ┌───┬───┬───┬───┬───┐
 A │ 0 │ 1 │ 2 │ ∞ │ ∞ │
   ├───┼───┼───┼───┼───┤
 B │ 1 │ 0 │ 3 │ ∞ │ ∞ │
   ├───┼───┼───┼───┼───┤
 C │ 2 │ 3 │ 0 │ 4 │ 5 │
   ├───┼───┼───┼───┼───┤
 D │ ∞ │ ∞ │ 4 │ 0 │ 7 │
   ├───┼───┼───┼───┼───┤
 E │ ∞ │ ∞ │ 5 │ 7 │ 0 │
   └───┴───┴───┴───┴───┘

特点:
• 矩阵对称(无向图)
• 对角线为0(无自环)
• 空间: O(V²)
• 查边: O(1)
• 适合稠密图
```

**邻接表 (Adjacency List)**：
```
图的邻接表表示:

A → [(B,1), (C,2)]
B → [(A,1), (C,3)]
C → [(A,2), (B,3), (D,4), (E,5)]
D → [(C,4), (E,7)]
E → [(C,5), (D,7)]

内存结构示意:
┌─────┐     ┌─────┐     ┌─────┐
│  A  │────→│ B,1 │────→│ C,2 │────→ NULL
└─────┘     └─────┘     └─────┘
   │
   ↓
┌─────┐     ┌─────┐     ┌─────┐     ┌─────┐
│  B  │────→│ A,1 │────→│ C,3 │────→ NULL
└─────┘     └─────┘     └─────┘
   │
   ↓
┌─────┐     ┌─────┐     ┌─────┐     ┌─────┐     ┌─────┐
│  C  │────→│ A,2 │────→│ B,3 │────→│ D,4 │────→│ E,5 │────→ NULL
└─────┘     └─────┘     └─────┘     └─────┘     └─────┘

特点:
• 空间: O(V+E)
• 查边: O(degree)
• 遍历邻居: O(degree)
• 适合稀疏图
```

### 2.3 图的优缺点
**优点**：
- **表达能力强**：能表示复杂的多对多关系
- **算法成熟**：有完善的图论算法体系
- **应用广泛**：社交网络、地图、电路等都能建模为图

**缺点**：
- **空间开销大**：特别是稠密图的邻接矩阵
- **算法复杂**：许多图问题（如最短路径）算法较复杂
- **NP难问题**：一些图问题是NP难的（如旅行商问题）

## 3. 常见的图算法

### 3.1 深度优先搜索（DFS - Depth First Search）
**概述**：
- 采用递归或栈方式进行遍历，尽可能深地搜索图的分支
- 适用于连通性检测、拓扑排序、求解迷宫等问题

**算法过程示意**：
```
DFS遍历过程 (从A开始):

初始图:          访问顺序: A → B → C → D → E

    ┌───┐
    │ A │ ← 起点
    └─┬─┘
      │
   ┌──┴──┐
   ↓     ↓
 ┌───┐ ┌───┐
 │ B │ │ C │
 └───┘ └─┬─┘
         │
      ┌──┴──┐
      ↓     ↓
    ┌───┐ ┌───┐
    │ D │ │ E │
    └───┘ └───┘

递归调用栈变化:
┌─────────────────────────────────────────┐
│ dfs(A)                                  │
│   ├─ dfs(B)  访问B，B无未访问邻居       │
│   │   └─ 返回                           │
│   ├─ dfs(C)  访问C                       │
│   │   ├─ dfs(D) 访问D，D无未访问邻居    │
│   │   │   └─ 返回                       │
│   │   └─ dfs(E) 访问E，E无未访问邻居    │
│   │       └─ 返回                       │
│   └─ 返回                               │
└─────────────────────────────────────────┘

访问顺序: A → B → C → D → E
```

**核心思想**：
- 从起始顶点开始，访问邻居顶点
- 对每个邻居递归进行DFS
- 使用visited数组避免重复访问

**应用**：
- 检测有向图是否有环
- 解决连通性问题
- 拓扑排序
- 求解迷宫问题
- 寻找强连通分量

**实现文件**：
- `graph_dfs.c` - 递归实现
- `graph_dfs_iterative.c` - 迭代实现

### 3.2 广度优先搜索（BFS - Breadth First Search）
**概述**：
- 采用队列方式进行逐层遍历
- 适用于最短路径搜索、网络流分析等

**算法过程示意**：
```
BFS遍历过程 (从A开始):

初始图:          访问顺序: A → B → C → D → E

    ┌───┐
    │ A │ ← 起点 (第0层)
    └─┬─┘
      │
   ┌──┴──┐
   ↓     ↓
 ┌───┐ ┌───┐
 │ B │ │ C │ ← 第1层
 └───┘ └─┬─┘
         │
      ┌──┴──┐
      ↓     ↓
    ┌───┐ ┌───┐
    │ D │ │ E │ ← 第2层
    └───┘ └───┘

队列变化过程:
步骤    队列            出队    访问    入队邻居
─────────────────────────────────────────────────
 1      [A]             A       ✓       [B, C]
 2      [B, C]          B       ✓       [C]    (C已在队列)
 3      [C]             C       ✓       [D, E]
 4      [D, E]          D       ✓       [E]    (E已在队列)
 5      [E]             E       ✓       []
 6      []              结束

访问顺序: A → B → C → D → E (按层遍历)
```

**核心思想**：
- 从起始顶点开始，访问所有邻居
- 将邻居加入队列，按FIFO顺序处理
- 保证先访问离起点近的顶点

**应用**：
- 最短路径搜索（无权图）
- Web爬虫
- 社交网络的好友推荐（二度好友）
- 最小生成树的Prim算法辅助

**实现文件**：
- `graph_bfs.c`

### 3.3 Dijkstra算法（最短路径）
**概述**：
- 计算从单一源点到其他所有顶点的最短路径
- 适用于加权图，但不支持负权边
- 贪心算法，时间复杂度O((V+E)log V)（使用优先队列）

**算法过程示意**：
```
Dijkstra算法过程 (从A开始):

初始图:
    ┌───┐ 4    ┌───┐ 1    ┌───┐
    │ A │──────│ B │──────│ C │
    └─┬─┘      └───┘      └─┬─┘
    2 │                     │ 3
      ↓                     ↓
    ┌───┐ 5    ┌───┐ 2    ┌───┐
    │ D │──────│ E │──────│ F │
    └───┘      └───┘      └───┘

算法执行过程:
┌─────────────────────────────────────────────────────────┐
│ 步骤 │ 当前顶点 │ 距离更新 │ 已确定最短距离              │
├──────┼─────────┼──────────┼────────────────────────────┤
│  0   │    A    │ A=0      │ {}                          │
│      │         │ 其他=∞   │                             │
├──────┼─────────┼──────────┼────────────────────────────┤
│  1   │    A    │ B=4      │ {A=0}                       │
│      │         │ D=2      │                             │
├──────┼─────────┼──────────┼────────────────────────────┤
│  2   │    D    │ E=7      │ {A=0, D=2}                  │
│      │ (最近)  │ (2+5)    │                             │
├──────┼─────────┼──────────┼────────────────────────────┤
│  3   │    B    │ C=5      │ {A=0, D=2, B=4}             │
│      │ (最近)  │ (4+1)    │                             │
├──────┼─────────┼──────────┼────────────────────────────┤
│  4   │    C    │ F=8      │ {A=0, D=2, B=4, C=5}        │
│      │ (最近)  │ (5+3)    │                             │
├──────┼─────────┼──────────┼────────────────────────────┤
│  5   │    E    │ F=9(不更)│ {A=0, D=2, B=4, C=5, E=7}   │
│      │ (最近)  │ (7+2)    │                             │
├──────┼─────────┼──────────┼────────────────────────────┤
│  6   │    F    │ 无       │ {..., F=8}                  │
└──────┴─────────┴──────────┴────────────────────────────┘

最终最短距离:
A=0, B=4, C=5, D=2, E=7, F=8
```

**核心思想**：
- 维护从源点到各顶点的最短距离估计
- 每次选择距离最小的未确定顶点
- 更新该顶点邻居的距离

**应用**：
- 地图导航（GPS路线规划）
- 网络路由优化（OSPF协议）
- 电路板布线
- 任务调度

**实现文件**：
- `graph_dijkstra.c`

## 5. 图算法技巧总结

### 5.1 图的遍历策略选择
```
┌──────────────────────────────────────────────────────┐
│ 场景                    │ 推荐算法                     │
├────────────────────────┼─────────────────────────────┤
│ 是否存在路径             │ DFS/BFS均可                  │
│ 最短路径（无权图）        │ BFS                         │
│ 最短路径（加权图）        │ Dijkstra                    │
│ 检测环                  │ DFS                         │
│ 拓扑排序                │ DFS                         │
│ 连通分量                │ DFS/BFS均可                  │
│ 迷宫问题                │ DFS(找解)/BFS(最短路径)       │
└────────────────────────┴─────────────────────────────┘
```

### 5.2 图的表示选择
- **稀疏图**（E << V²）：使用邻接表，节省空间
- **稠密图**（E ≈ V²）：使用邻接矩阵，快速查边
- **需要快速判断边是否存在**：邻接矩阵
- **需要遍历邻居**：邻接表

## 6. 性能特点

### 6.1 时间复杂度
| 算法 | 时间复杂度 | 说明 |
|------|----------|------|
| DFS | O(V+E) | 访问所有顶点和边 |
| BFS | O(V+E) | 访问所有顶点和边 |
| Dijkstra | O((V+E)log V) | 使用优先队列 |
| 最短路径（Floyd） | O(V³) | 所有点对 |
| 最小生成树（Prim） | O(E log V) | 使用优先队列 |
| 最小生成树（Kruskal） | O(E log E) | 排序边 |

### 6.2 空间复杂度
| 表示方式 | 空间复杂度 | 适用场景 |
|---------|----------|---------|
| 邻接矩阵 | O(V²) | 稠密图 |
| 邻接表 | O(V+E) | 稀疏图 |
| 边列表 | O(E) | 简单遍历 |
