# 数学（Math）算法概述

## 1. 什么是数学算法？
数学算法是解决数值计算、数论问题、代数运算、几何计算等数学问题的算法集合。数学算法是计算机科学的基础，在密码学、图形学、机器学习、工程计算等领域有核心应用。

**数学算法的分类示意**：
```
数学算法分类
├── 数论算法
│   ├── 质数判定        → 素性测试、筛法
│   ├── 质因数分解      → 大数分解、加密基础
│   ├── GCD/LCM         → 欧几里得算法
│   └── 模运算          → 同余方程、逆元
│
├── 代数算法
│   ├── 矩阵运算        → 加减乘除、行列式
│   ├── 线性方程组      → 高斯消元
│   ├── 多项式运算      → 求值、插值
│   └── 快速幂          → 模幂运算
│
├── 组合数学
│   ├── 排列组合        → 阶乘、组合数
│   ├── 斐波那契        → 通项、矩阵快速幂
│   └── 卡特兰数        → 计数问题
│
├── 数值计算
│   ├── 浮点精度        → 误差处理
│   ├── 数值积分        → 近似计算
│   └── 方程求根        → 牛顿迭代
│
└── 几何算法
    ├── 点线面计算      → 距离、交点
    ├── 凸包算法        → Graham扫描
    └── 最近点对        → 分治算法
```

## 2. 数学算法的基本特性

### 2.1 数学问题的特点
- **精确性要求**：数学计算通常要求精确或高精度的结果
- **理论支撑**：基于数学定理和证明
- **计算复杂度**：有些问题（如大数分解）计算复杂度极高
- **数值稳定性**：浮点运算需要注意精度损失

### 2.2 计算精度示意
```
浮点数表示的精度问题:

IEEE 754 双精度浮点数 (64位):
┌────────┬─────────────────────┬───────────────────────────┐
│ 符号位  │     指数位 (11位)    │       尾数位 (52位)         │
│  1 bit │                     │                           │
├────────┼─────────────────────┼───────────────────────────┤
│   0    │   01111111111       │  101010... (52 bits)      │
│ (+/-)  │   (偏移1023)         │   (精度约15-16位十进制)     │
└────────┴─────────────────────┴───────────────────────────┘

精度损失示例:
0.1 + 0.2 = 0.30000000000000004 (不等于0.3)

原因: 0.1在二进制中是无限循环小数
0.1₁₀ = 0.0001100110011...₂
```

### 2.3 数学算法的优缺点
**优点**：
- **通用性强**：数学问题是各领域的基础
- **结果可验证**：数学结果可以严格证明或验证
- **高度优化**：经典算法经过长期优化，效率极高
- **硬件支持**：现代CPU有专门的数学运算指令

**缺点**：
- **数值误差**：浮点运算可能累积误差
- **溢出风险**：大数运算可能超出数据类型范围
- **复杂度限制**：某些问题（如NP难问题）无高效算法
- **精度与效率权衡**：高精度计算通常更慢

## 3. 常见的数学算法

### 3.1 质数判定（Prime Check）
**概述**：
- 判断一个数是否为质数（只能被1和自身整除）
- 基础版本试除到√n，高效版本使用Miller-Rabin测试

**算法过程示意**：
```
质数判定 - 试除法优化:

判断 97 是否为质数:

试除范围: 2 到 √97 ≈ 9.8

步骤:
┌────────┬──────────┬──────────┐
│ 除数    │  97%除数  │   结果   │
├────────┼──────────┼──────────┤
│   2    │  97%2=1  │  不能整除 │
│   3    │  97%3=1  │  不能整除 │
│   5    │  97%5=2  │  不能整除 │
│   7    │  97%7=6  │  不能整除 │
└────────┴──────────┴──────────┘

97 是质数!

优化技巧:
• 只需试除到 √n (如果n有因子大于√n，则必有对应小于√n的因子)
• 只需试除质数 (2, 3, 5, 7...)
• 大于2的偶数都不是质数
• 6k±1 形式检验 (所有质数>3都可表示为6k±1)

时间复杂度: O(√n)
```

**核心思想**：
- 只需检查到√n即可
- 只需检查质数除数
- 使用6k±1优化减少检验次数

**应用**：
- 密码学（RSA依赖大质数）
- 哈希表容量选择
- 随机数生成

**实现文件**：
- `number/isPrime.c`

### 3.2 最大公约数 GCD（Greatest Common Divisor）
**概述**：
- 计算两个数的最大公约数
- 经典算法：欧几里得算法（辗转相除法）

**欧几里得算法示意**：
```
计算 GCD(48, 18):

欧几里得算法原理:
gcd(a, b) = gcd(b, a mod b)
gcd(a, 0) = a

计算过程:
┌─────────────────────────────────────────┐
│ gcd(48, 18)                             │
│   = gcd(18, 48 mod 18)                  │
│   = gcd(18, 12)                         │
│       = gcd(12, 18 mod 12)              │
│       = gcd(12, 6)                      │
│           = gcd(6, 12 mod 6)            │
│           = gcd(6, 0)                   │
│           = 6                           │
└─────────────────────────────────────────┘

验证:
48 = 6 × 8
18 = 6 × 3
GCD = 6 ✓

最小公倍数 LCM:
lcm(a, b) = |a × b| / gcd(a, b)
lcm(48, 18) = (48 × 18) / 6 = 144

扩展欧几里得算法:
可求出 ax + by = gcd(a, b) 中的x和y
用于求解模逆元
```

**核心思想**：
- gcd(a, b) = gcd(b, a mod b)
- 递归直到余数为0

**应用**：
- 分数约简
- 密码学（模逆元）
- 数论问题

**实现文件**：
- `number/gcd.c`

### 3.3 质因数分解（Prime Factorization）
**概述**：
- 将一个合数分解为质数的乘积
- 基础方法：试除法；高效方法：Pollard's Rho（大数）

**试除法分解示意**：
```
分解 360:

试除过程:
┌──────────┬────────────┬────────────┬──────────┐
│  步骤    │   当前数    │   试除数   │   结果   │
├──────────┼────────────┼────────────┼──────────┤
│    1     │    360     │     2      │ 360/2=180│
│    2     │    180     │     2      │ 180/2=90 │
│    3     │     90     │     2      │  90/2=45 │
│    4     │     45     │     2      │ 不能整除 │
│    5     │     45     │     3      │  45/3=15 │
│    6     │     15     │     3      │  15/3=5  │
│    7     │      5     │     3      │ 不能整除 │
│    8     │      5     │     5      │   5/5=1  │
└──────────┴────────────┴────────────┴──────────┘

结果: 360 = 2³ × 3² × 5

质因数分解树:
        360
       /   \
      2     180
           /   \
          2     90
               /  \
              2    45
                  /  \
                 3    15
                     /  \
                    3    5
```

**核心思想**：
- 从最小质数2开始试除
- 能整除则记录该因子并继续除
- 除数递增直到平方大于被除数

**应用**：
- 密码学（RSA安全性依赖分解难度）
- 简化分数
- 计算约数个数和约数和

**实现文件**：
- `factor/` 目录下的多种实现

### 3.4 快速幂（Fast Exponentiation）
**概述**：
- 高效计算 aⁿ 的算法
- 时间复杂度 O(log n) 而非 O(n)

**快速幂算法示意**：
```
计算 3¹⁰:

普通方法: 3×3×3×...×3 (10次乘法)
快速幂: 利用二进制分解

10 的二进制: 1010 = 8 + 2

计算过程 (迭代法):
┌────────┬────────────┬─────────────┬──────────────┐
│  步骤   │     n      │    底数     │    结果       │
├────────┼────────────┼─────────────┼──────────────┤
│  初始   │     10     │      3      │      1       │
│   1    │ 10/2=5     │  3²=9       │  1(偶数不乘)  │
│   2    │  5/2=2     │  9²=81      │  1×9=9       │
│   3    │  2/2=1     │  81²=6561   │  9(偶数不乘)  │
│   4    │  1/2=0     │  6561²      │  9×6561      │
│        │            │             │  =59049      │
└────────┴────────────┴─────────────┴──────────────┘

验证: 3¹⁰ = 59049 ✓

时间复杂度: O(log n)
只需4次循环而非10次乘法
```

**核心思想**：
- n 的二进制表示决定哪些幂次要乘
- 底数不断平方，指数不断折半
- 模运算结合：防止溢出

**应用**：
- 大数幂运算
- 密码学（RSA加密）
- 矩阵快速幂

**实现文件**：
- `number/binary.c` 或各语言的快速幂实现

### 3.5 斐波那契数列（Fibonacci）
**概述**：
- F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)
- 多种计算方法：递归、迭代、通项公式、矩阵快速幂

**计算方法对比示意**：
```
计算 Fibonacci(10) = 55:

方法1: 递归 (时间复杂度 O(2ⁿ))
                    fib(5)
                  /        \
            fib(4)          fib(3)
           /      \        /      \
      fib(3)    fib(2)  fib(2)   fib(1)
      /    \    /    \   /    \
   fib(2) fib(1) ...
   
大量重复计算!

方法2: 迭代 (时间复杂度 O(n), 空间 O(1))
a=0, b=1
for i=2 to n:
    c = a + b
    a = b
    b = c

方法3: 矩阵快速幂 (时间复杂度 O(log n))
┌          ┐ⁿ   ┌               ┐
│ 1  1     │    │ F(n+1)  F(n)  │
│ 1  0     │  = │ F(n)    F(n-1)│
└          ┘    └               ┘

方法4: 通项公式 (比内公式)
F(n) = (φⁿ - ψⁿ) / √5
其中 φ=(1+√5)/2≈1.618 (黄金比例)
     ψ=(1-√5)/2≈-0.618

注意: 浮点数精度问题，n大时不准确
```

**核心思想**：
- 迭代法最实用
- 矩阵快速幂适合超大n
- 通项公式理论意义大于实用

**应用**：
- 自然界现象（植物排列）
- 金融分析
- 算法复杂度分析

**实现文件**：
- `number/fibonacci.c`

## 5. 算法技巧总结

### 5.1 数论技巧
```
常用数论公式:
┌─────────────────────────────────────────┐
│ 欧拉函数: φ(n) = n × Π(1 - 1/p)          │
│   (p是n的所有不同质因子)                   │
│                                         │
│ 模运算性质:                               │
│ (a + b) mod m = ((a mod m) + (b mod m)) mod m  │
│ (a × b) mod m = ((a mod m) × (b mod m)) mod m  │
│ aⁿ mod m 可用快速幂计算                   │
│                                         │
│ 费马小定理: a^(p-1) ≡ 1 (mod p)           │
│   (p是质数，a不是p的倍数)                  │
└─────────────────────────────────────────┘
```

### 5.2 精度处理技巧
- **避免直接比较浮点数**：使用epsilon容差
- **大数运算**：使用数组或字符串表示
- **分数运算**：保持分子分母，避免浮点转换
- **Kahan求和**：减少浮点累加误差

## 6. 性能特点

### 6.1 时间复杂度
| 算法 | 时间复杂度 | 说明 |
|------|----------|------|
| 质数判定（试除） | O(√n) | 基础版本 |
| 质数判定（Miller-Rabin） | O(k log³n) | 概率算法，k为迭代次数 |
| GCD（欧几里得） | O(log min(a,b)) | 非常高效 |
| 快速幂 | O(log n) | 二进制分解 |
| 斐波那契（矩阵） | O(log n) | 矩阵快速幂 |

### 6.2 空间复杂度
- 大多数数学算法空间复杂度为 O(1)
- 大数运算需要 O(n) 空间存储数字
- 递归实现需要 O(log n) 栈空间

## 7. 编程语言支持

- **C**：基础实现，注意溢出处理，使用`<math.h>`
- **Java**：BigInteger类支持大数运算
- **Go**：math/big包支持高精度计算
- **JavaScript**：Number精度限制，可用库处理大数
- **Python**：原生支持大整数，无需特殊处理
- **Rust**：类型安全，溢出检查严格
